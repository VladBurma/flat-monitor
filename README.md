# Моніторинг оренди: ЖК Нова Англія

Кожні 15 хвилин GitHub Actions перевіряє LUN, DOM.RIA і Rieltor (LUN також підтягує оголошення з OLX; Flatfy і OLX напряму блокують сервери GitHub) і надсилає нові підходящі квартири в Telegram-бот.

## Фільтри

Їх задано в `config.json`:

- ціна до `max_price_uah` грн (доларові ціни перераховуються за курсом НБУ);
- площа від `min_area` м²;
- поверх до `max_floor` включно. Якщо поверх не вказано, оголошення все одно надходить.

Щоб змінити фільтр, відредагуйте `config.json` прямо на GitHub і натисніть Commit.

## Як це працює

- `seen.json` зберігає вже бачені оголошення, щоб не надсилати їх повторно.
- Одна квартира, розміщена на кількох сайтах, надходить один раз.
- Якщо котрийсь сайт не відповідає приблизно 2 години, бот про це напише.

## Керування

- **Пауза:** вкладка Actions → flat-monitor → «…» → Disable workflow.
- **Перевірити зараз:** Actions → flat-monitor → Run workflow.
- **Токен бота** зберігається в Settings → Secrets → Actions → `TELEGRAM_TOKEN`.
